# TRS Rush — 蟲洞跑酷射擊（網頁雛形）

**▶ 立即遊玩：https://cycymk.github.io/TRS_Rush_2026/** （手機橫向開啟，支援陀螺儀）

手機陀螺儀操控的 3D 太空船跑酷／射擊遊戲。這一版是 **可以玩的雛形**，用來驗證手感、節奏和玩法循環，之後要換成 Unity 或繼續用網頁版都可以沿用這份設計。

## 怎麼跑起來

```bash
node server.js
```

電腦打開 http://localhost:5173 就能玩（滑鼠／鍵盤操作）。

### 用手機玩（陀螺儀）
手機瀏覽器規定：**陀螺儀只能在 HTTPS 網址下使用**。區網的 `http://192.168.x.x:5173` 可以開，但會變成只能用手指拖曳操作。要測陀螺儀，三種方式擇一：

1. 把整個資料夾丟到 GitHub Pages / Netlify / Vercel（純靜態檔，不需要後端）
2. 用 `npx localtunnel --port 5173` 或 Cloudflare Tunnel 暫時開一個 HTTPS 網址
3. iPhone 第一次按「啟動引擎」會跳出動作感應權限，要按允許

## 操作

| 動作 | 手機 | 電腦 |
|---|---|---|
| 移動飛船 | 傾斜手機（開局的姿勢＝置中） | 滑鼠位置 / WASD / 方向鍵 |
| 微調位置 | 手指在畫面上拖曳 | — |
| 翻滾閃避（短暫無敵） | 快速左右滑一下 | Q / E |
| 超光速衝刺 | 左下 BOOST | 空白鍵 |
| 換武器 | 右下四顆按鈕 | 1–4 |
| 破解 BOSS 護盾 | 中下 HACK | H |
| 重新校正陀螺儀 | 右上 ◎ | R |

武器會自動開火，玩家專心在閃避和選武器上。

## 一輪的流程

```
WAVE 1 ──► 閘門（三選一 或 破解）──► WAVE 2 ──► 閘門 ──► WAVE 3 ──► BOSS ──► 結算 ──► 整備升級 ──► 下一輪（更快、更難、換配色）
```

- **跑酷波**：隕石從蟲洞深處飛來。大隕石被打碎會裂成兩顆小的；第二波開始會出現「隕石牆」，只留一個缺口，或用擴散炮硬轟出一條路。擦身而過有 NEAR MISS 加分。
- **加速道具**：藍色八面體＝加速核心（存起來按 BOOST 用）；金色圓環＝穿過去立刻免費加速；綠色＝修復。
- **超光速衝刺**：速度 ×3.4、視角瞬間先拉近再猛拉遠、白閃、速度線、隧道條紋拉長；期間無敵且直接撞碎隕石，射速 ×1.5。衝刺也會讓這一波更快結束 → 衝「最快通關」。
- **閘門**：每輪兩個，輪流出現
  - 三選一卡片：加速核心 ×2、奈米修復、武器超頻、偏折護盾、資源艙、超載起步、能量電容
  - 破解小遊戲：獎勵加速核心 + 點數
- **BOSS「GUARDIAN」**：護盾展開時打不動 → 按 HACK 進入破解（世界變慢動作，但敵彈還在飛）→ 成功後護盾消失約 10 秒，BOSS 隨機進入一種狀態，要換成對應武器才打得痛（×3 傷害，其他武器只有 ×0.35）：

| BOSS 狀態 | 行為 | 弱點武器 |
|---|---|---|
| 重裝甲 | 一般移動 | PULSE 單發（高傷害） |
| 蜂群展開 | 放出 6 架會射擊的無人機 | SCATTER 擴散 |
| 核心暴露 | 高速亂飛 | LASER 光束（持續追瞄） |
| 自我修復 | 持續回血 | VULCAN 連射 |

  破解時多拿到的 ◆ 會延長破盾時間。破解失敗會被護盾反擊。

## 破解小遊戲（參考 Pragmata）

在格子上從「起點」用手指畫一條路到「終點」，限時完成。
- 紅色斜線格是障壁，不能穿過；走過的格子不能重複走，往回退一格可以反悔
- ◆ 是加成，有一顆刻意放在需要繞路的位置 → 要不要冒時間風險去拿
- 每一關都是先隨機走出一條保證可解的路，再把其他格子隨機變障壁，所以 **一定有解**

## 武器

| 武器 | 特性 | 等級提升 |
|---|---|---|
| PULSE 單發 | 慢、單發傷害高，有較強的輔助瞄準 | 傷害、射速 |
| VULCAN 連射 | 快、單發弱，會自動攔截敵彈 | 傷害、射速 |
| SCATTER 擴散 | 一次射出 5/7/9 發散彈，射程短 | 彈數、傷害 |
| LASER 光束 | 持續命中最前方目標，消耗能量（能量歸零要等回到 35% 才能再開） | 每秒傷害 |

## 畫面（Unreal 風格）

- **後製**：HDR 渲染 → Unreal 同款泛光（UnrealBloomPass）→ 鏡頭效果（色散、超光速放射模糊、暗角、底片顆粒）→ ACES 電影色調
- **材質**：飛船與 BOSS 用烤漆金屬（清漆層），會映出蟲洞的光；反射環境依每輪配色自動產生
- **隕石**：程式生成的顏色／凹凸／粗糙度貼圖，大隕石有發光的岩漿裂縫；水晶隕石有虹彩
- **特效**：引擎尾跡、爆炸衝擊波＋碎石＋瞬間照亮周圍的閃光、BOSS 邊緣發亮的能量護盾
- **畫質選項**（標題畫面）：低＝關閉後製（省電）、中＝手機預設、高＝電腦預設；掉幀時會自動降低解析度保持流暢

## 排行榜

存在瀏覽器本機（localStorage），四個分頁：
- **總分**、**最多擊落**：以「一整趟航程」計（死亡或在整備艙按結束）
- **最快通關**、**無損通關**：每打倒一隻 BOSS 記一筆該輪的通關時間

分數來源：飛行距離、擊落、擦身而過、穿過金環、BOSS 擊破（5000 × 輪數）、時間獎勵、無損獎勵 5000。

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html` / `style.css` | 介面（HUD、各種彈出畫面） |
| `src/main.js` | 遊戲主體：蟲洞隧道著色器、飛船、陀螺儀、武器、隕石、BOSS、流程 |
| `src/hack.js` | 破解小遊戲 |
| `src/graphics.js` | 後製特效、反射環境、程式生成貼圖、BOSS 護盾著色器 |
| `src/audio.js` | 即時合成音效（不需要音檔） |
| `src/storage.js` | 本機排行榜與設定 |
| `server.js` | 本機測試伺服器 |

數值都集中在 `src/main.js` 最上面（`WEAPONS`、`BOSS_STATES`、速度、波長等），調手感從那裡改。

## 已知限制 / 下一步建議

- 排行榜目前只在自己的手機上，要「跟別人比」需要一個線上後端（例如 Firebase / Supabase）
- 只有一種 BOSS；可以每輪換外型與攻擊模式
- 模型仍是程式生成的幾何體，之後可換成正式 3D 模型（glTF）
- 還沒做背景音樂、震動回饋只有 Android 支援（iPhone 瀏覽器不支援震動）
- 隧道彎曲只是視覺效果，碰撞仍是直線判定（靠近飛船的地方彎曲趨近 0，所以操作上感覺不到）
